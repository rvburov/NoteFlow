# Django Notes Application

## Описание
Приложение **Django Notes Application** позволяет пользователям создавать, редактировать, удалять и просматривать заметки. Проект включает систему аутентификации, работу с базой данных SQLite и тестовый набор для проверки основных функций приложения.

---

## Функционал

- **Аутентификация:**
  - Регистрация пользователей
  - Логин и логаут

- **Работа с заметками:**
  - Создание заметок
  - Редактирование заметок
  - Удаление заметок
  - Просмотр списка заметок и деталей

- **Тестирование:**
  - Покрытие основных функций приложения через `pytest`

## Установка и запуск

### Шаги установки
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-repo/ya_note.git
   cd ya_note
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Выполните миграции базы данных:
   ```bash
   python manage.py migrate
   ```

5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

6. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) в браузере.

## Тестирование

1. Запустите тесты:
   ```bash
   pytest
   ```

2. Используйте скрипт для проверки тестов и структуры проекта:
   ```bash
   ./run_tests.sh
   ```

## Требования

- Python 3.11+

- **Pytest:**
  - Покрытие тестами основных функций приложения
